Parliament is not a single moral oracle. Given a written dilemma, it first builds a shared world from the sentences — who acts, what is scarce, what happens if — then lets five independent ethical viewpoints argue from that world. Extra stories that are not in the graph are marked hypothetical and lose vote weight. The output still shows disagreement, conditions, and what would change the answer.

1 English dilemma→ 2 Syntax + exclusivity→ 3 Admitted world graphs→ 4 Five independent lenses→ 5 Contested judgment

The case, as written

Five workers are on the track. One worker is on the side track. Maria can pull the lever, but not the brake. If Maria pulls the lever, one worker will die. If Maria does not pull the lever, five workers will die.

Syntax of the hard sentence

“Can” is ability, not obligation. “But not the brake” blocks a second control; it is not “but not both.” Omission is recovered as a live action, not treated as doing nothing.

What gets admitted

Parser proposes; Parliament admits. This run used a frozen world — 0 world-generation calls — so agents argued on the committed graph, not a regenerated one. Chosen blueprint: omission_harm.
