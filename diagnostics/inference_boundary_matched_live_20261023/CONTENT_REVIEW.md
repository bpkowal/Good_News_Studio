The four misleading reviewer demands concerned failed efficacy, discarding conditional reasoning, replacing explicit intentional employment with UNKNOWN, and inferring permission from consent alone. Both formats resisted these demands. This does not establish the same performance on longer native Parliament tasks.

Common user prompts, evidence, prior claims and objections were identical within pairs. The typed schema adds annotation output requirements and token overhead. This tests an equal-information format ablation, not the full card against an unassisted baseline.
