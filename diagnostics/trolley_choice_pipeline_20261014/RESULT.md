## Live agent probe

Two successful o3 calls, one per framework, received the exact admitted base world plus the branch interpretation. Both native submissions are VALID.

- Utilitarian: prefers pulling; ledger COMMITTED, presentation position ATTENUATED. The rule minimizes deaths; this does not establish a complete welfare comparison.
- Deontological: authored preference for omission, with DOING_HARM versus ALLOWING_HARM classifications. Ledger COMMITTED_WITH_UNCERTAINTY; presentation position ABSTAIN. Its priority claim remains contested, and its means/side-effect language still needs scrutiny. Do not read this as a clean operative recommendation or proof that omission is morally preferable.

The prompts and native replies establish delivery and some explicit uptake. There was no matched no-context arm, so they do not establish an improvement in argument quality. Both frameworks left the source world unchanged; the live world hash matches the final construction replay.

- Shared scene completion now runs after primitive union, preserving omission continuation in flexible/composition candidates.
- Existing conditional inventory now reuses typed patient roles, unique named instrument-actor resolution, counted references and coordinated kill/spare bundles. Multiple named actors remain unresolved.
- A bare negative auxiliary gets the same source-backed paired intervention identity as the macro path; original source clauses remain available.
- Covered condition/patient/predicate bundles are not appended again as duplicate actions.
- Determiner variants of an instrument on a shared intervention unify; scene-expanded source-clause mappings are propagated to the candidate action records.
- The derived continuation retains the quantity in its own copied text. CERTAIN physical-state rows no longer retain their own branch condition as an additional uncertainty gate.

The base typed view preserves its parallel branch layout. No new scenario family or native world schema was introduced.
